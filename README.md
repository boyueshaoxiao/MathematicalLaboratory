# 几何空间实验室

纯前端 Vue 3 + Three.js 几何互动工具。

## 功能

- 多种 3D 几何图形
- N 棱柱 / N 棱锥参数化
- 多图形组合
- 鼠标旋转与缩放
- 前后左右上下视图
- 对象位置/旋转/缩放编辑
- 网格、棱线、半透明显示
- 无后端、无数据库、无登录

## 启动

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```


## 新增：单个几何体展开图

进入顶部“单体展开图”模式，可以选择：
- 正方体：3 种展开方式
- 长方体：2 种展开方式
- 三棱柱：2 种展开方式
- 圆柱：2 种展开方式
- 圆锥：2 种展开方式
- 四棱锥：2 种展开方式

支持：
- 展开程度 0%～100% 拖动
- 自动展开动画
- 完全展开 / 折叠
- 鼠标旋转、缩放
- 同一几何体切换不同展开方式

这是面向小学生的第一版“展开图实验”模块，后续可以继续增加更多合法展开图组合、折痕高亮、顶点/面编号以及“从展开图猜立体”的练习模式。
